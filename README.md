

# Personal Link Saver (CLI)

A beginner-friendly Python command-line application to save and manage useful URLs.

## Features

- Add new links with title, URL, and category.
- View all saved links.
- Search links using title keywords.
- Delete links using their ID.
- Automatically assign IDs to new links.
- Menu-driven command-line interface.

## Technologies

- Python
- Lists and Dictionaries
- Functions
- Loops and Conditional Statements
- String Operations

## Current Status

**Version 1.0 — In-memory storage**

Links are currently stored in a Python list of dictionaries. Data persistence using JSON is planned for the next version.

## Future Improvements

- JSON-based permanent storage.
- Input validation and exception handling.
- Improved ID generation.
- Better modular code structure.

## How to Run

```bash
python main.py
```
